# راه‌اندازی محیط آزمایشی

این تنظیمات برای محیط آزمایشی با داده ساختگی است. در پلن رایگان Render فایل‌سیستم موقت است و سرویس پس از ۱۵ دقیقه بی‌کاری خاموش می‌شود؛ بنابراین فایل‌ها در باکت خصوصی Supabase نگهداری می‌شوند.

## منابع موردنیاز

1. یک پروژه Supabase بسازید و از بخش Database، نشانی اتصال PostgreSQL را بردارید. برای Render از نشانی Connection Pooler استفاده کنید و رمز دیتابیس را فقط در فرم امن متغیرهای محیطی وارد کنید.
2. در Storage یک باکت خصوصی به نام `driver-documents` بسازید.
3. از بخش API Keys کلید محرمانه `service_role` را بردارید. این کلید دسترسی مدیریتی دارد و فقط در متغیرهای محیطی سرویس API قرار می‌گیرد؛ آن را در مرورگر، کد یا Git نگذارید.
4. در Render مخزن GitHub را به‌عنوان Blueprint وارد کنید و `render.yaml` را انتخاب کنید. مقدارهای `DATABASE_URL`، `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` را در داشبورد Render وارد کنید.
5. بعد از Deploy، صفحه را باز کنید و اولین حساب Super Admin را با توکن Bootstrap که Render ساخته راه‌اندازی کنید. سپس حساب‌های آزمایشی را بسازید.

مهاجرت دیتابیس هنگام شروع سرویس اجرا می‌شود. آدرس و توکن راه‌اندازی را در کد یا Git ثبت نکنید. تا وقتی این محیط روی پلن رایگان و سرویس‌های ابری عمومی است، فقط از اطلاعات ساختگی استفاده کنید.
